# CPU-intro 作业答案
## 1.
命令：python3 process-run.py -l 5:100,5:100
CPU利用率：100%
解释：两个进程都是纯CPU指令，没有IO。系统等到一个进程完全执行完毕才切换，全程CPU没有空闲等待，利用率100%。

## 2.
命令：python3 process-run.py -l 4:100,1:0
CPU利用率：约71.4%
解释：进程0先跑完4条CPU指令，之后运行进程1的IO指令。IO等待阶段CPU空闲，所以利用率低于100%。

## 3.
命令：python3 process-run.py -l 1:0,4:100
CPU利用率：100%
对比第2题：
本题IO进程最先运行，发起IO后立刻切换进程，在IO等待的同时CPU执行进程1的计算任务，没有空闲周期，利用率100%。第2题是CPU任务先跑完，IO等待时CPU空闲。

## 4.
命令：python3 process-run.py -l 5:100 -c
说明：-c 参数开启逐周期详细追踪，打印每个时间点进程运行状态。可以看到进程0在5个周期持续占用CPU，没有IO、没有空闲。

## 5.
命令：python3 process-run.py -l 4:100,1:0 -p
说明：-p 参数打印进程执行轨迹。进程0先连续执行4条CPU指令，之后切换到进程1执行IO；IO期间进程1进入阻塞等待。

## 6.
命令：python3 process-run.py -l 2:0,2:0 -c
说明：构造两个IO密集型进程。进程执行IO后进入BLOCKED阻塞状态，IO等待阶段没有就绪进程，CPU大量空闲，CPU利用率很低。
